# Smart City Waste Collection System

A Flask-based web application designed to make waste collection monitoring easier through an interactive dashboard.

## Features
- Waste bin monitoring dashboard
- High-priority waste bin identification
- Interactive map using Leaflet
- Waste statistics using charts
- Waste collection status tracking
- CSV-based sample data

## Technologies Used
- Python
- Flask
- HTML and CSS
- JavaScript
- Leaflet.js
- Chart.js
- CSV

## How to Run

1. Clone this repository.
2. Install the required Python packages.
3. Run the Flask application.

```bash
pip install flask
python app.py
```

4. Open the local URL shown in the terminal.
